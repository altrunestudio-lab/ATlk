# APgr Render Set

A single gallery of APgr renders.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload all extracted files, including the images folder.
2. In repository Settings → Pages, choose Deploy from a branch, select main and / (root), then save.

To change images or captions, open the separate `apgr-editor.html` file in your browser, make edits, and use Export GitHub ZIP again.
