# ATlk Render Set

A single gallery of 12 ATlk renders with the 2 Architects logo.

## Publish on GitHub Pages

1. Commit and push the changes in this repository, including `2 Architects logo.jpg`.
2. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

To change renders later, replace the files in `images/` and update the matching cards in `index.html`.
